#### 2. Script de Compilación `render-build.sh`
Render corre sobre un sistema Linux puro donde se necesitan herramientas binarias externas (`ffmpeg` y `shaka-packager`) para procesar el audio[cite: 6]. Crea este archivo para descargarlas automáticamente:
```bash
#!/usr/bin/env bash
set -o errexit

# Instalar dependencias de Python
pip install -r requirements.txt

# Crear directorio bin y descargar binarios estáticos para Linux
mkdir -p bin
curl -L https://github.com/shaka-project/shaka-packager/releases/download/v3.2.0/packager-linux-x64 -o bin/packager-linux-x64
chmod +x bin/packager-linux-x64
